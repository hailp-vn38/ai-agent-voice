# ADR 0053 — External MCP fail-soft trong V1

## Status

Superseded in part, 2026-10-08 by the MCP Tool Authorization refactor: External discovery remains fail-soft, but publication and dispatch now require current Agent approval in every Speaker Policy.

External MCP unavailable, initialize/tools-list failure, timeout, invalid tools list hoặc tool-name collision chỉ loại tools của server lỗi khỏi snapshot; Voice Session vẫn hoạt động và không dùng stale tools như đã verify. Mỗi admission lấy fresh paginated tool snapshot trong per-server/overall bounded budget, dù có thể reuse HTTP transport. A validated binding publishes only the Agent-approved, non-sensitive tools with their current exact observed contract fingerprint, regardless of Speaker Policy. Snapshot Session Tool Catalog sau admission immutable đến disconnect; approval additions apply only to a new session, while revocation or drift blocks a new outbound start and closes the affected WebSocket. Raw/untrusted catalog bị cap trước LLM conversion; per-server/page/schema/description overflow reject server, còn aggregate session overflow exclude toàn bộ External MCP snapshot, không partial/bind-order choice và không ảnh hưởng Device MCP. Device MCP dùng `self.<tool>`, External MCP dùng `external.<normalized_server_key>.<normalized_tool_name>`, và typed Tool Origin route về original name thay vì tin LLM-visible name. Normalization pure, bounded, không truncate/hash; tên invalid bị bỏ, collision nội bộ reject server, không first/last/bind-order wins. Mỗi External Tool Call có đúng một bounded outbound attempt, không retry vì side effect có thể non-idempotent; shared process-global semaphore per server (`1..=64`, default 16) chờ trong turn budget và khi không acquire kịp thì không gửi request, trả `external_tool_unavailable`. Failure trả typed synthetic ToolResult cho LLM continuation, không đóng Voice Session. `agent_mcp_bindings.required` tồn tại với default false để mở rộng sau này, nhưng V1 chỉ hỗ trợ false.
