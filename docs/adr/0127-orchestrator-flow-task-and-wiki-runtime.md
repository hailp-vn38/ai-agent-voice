# ADR 0127 — Unified Task, Reminder, and Wiki Auto-Flow Runtime via `orchestrator-flow`

Status: Accepted, 2026-10-22.
Supersedes: [ADR 0093](0093-executable-python-plugin-runtime.md), [ADR 0094](0094-rust-owned-job-dag-orchestration.md), [ADR 0099](0099-rust-executable-plugin-runtime.md), [ADR 0103](0103-hierarchical-agent-job-v2.md), [ADR 0114](0114-opencode-agent-session-tool-delegation.md), [ADR 0114 (Core Operations)](0114-core-operations-in-process.md), [ADR 0117](0117-knowledge-core-plugin-adapter.md), [ADR 0120](0120-three-sqlite-database-lifecycles.md), [ADR 0123](0123-knowledge-ingest-job-execution-and-review-policy.md), [ADR 0125](0125-knowledge-job-tools-skills-and-publication.md), [ADR 0126 (Anydoc)](0126-core-document-anydoc-and-large-tool-results.md), [ADR 0126 (yt-dlp)](0126-yt-dlp-cli-provisioned-core-runtime.md).

`voice-agent-server` retires its in-crate background Job engine (`services/background`), SQLite `jobs`/`plugins` tables (`database/jobs`, `database/plugins`, `database/core_plugins`), subprocess plugin runner (`plugin-runtime`), and `tools/core` adapters in favor of `orchestrator_flow_rs` (`orchestrator-flow`), `orchestrator_agent_rs`, and `llm-wiki-rs`. A two-phase `TaskManager` owns `tasks.db` and `tasks.owner.lock`, coordinates a two-flow `Orchestrator` (`daily_root` for interactive research/staging/reminders and `wiki_root` for Karpathy LLM Wiki collection/ingestion/curation), and drives `WikiAutoFlowBinding` whenever new Markdown sources arrive in `sources/`.

## Consequences

- **Voice Session Builtin Tools**: Admitted Voice Sessions replace `server_create_job` with the nine `TaskToolSuite` builtins (`task_create`, `task_followup`, `task_list`, `task_detail`, `task_cancel`, `reminder_create`, `reminder_list`, `reminder_complete`, `reminder_delete`) scoped to the session's `device:<device_db_id>` and `agent_id`. Destructive `task_delete` remains Admin-only.
- **Admin HTTP Compatibility**: `/api/admin/jobs*` and `/api/admin/background/settings` remain mounted for Admin Web UI compatibility, projecting `TaskView` and `TaskDetailView` records from `TaskManager` and adding `/api/admin/jobs/{id}/followup` and `/api/admin/jobs/{id}/history`. `/api/admin/plugins*` and `/api/admin/core-plugins*` are removed because agent capabilities are compiled into `WorkspaceToolKit`.
- **Database Lifecycle**: The control-plane database (`voice-agent.db`) owns Devices, Agents, Templates, Providers, Speakers, and Transcripts; `TaskManager` owns `tasks.db`; `WikiEngine` owns the Markdown vault and its derived hybrid index.
