# Testing 01 — WebSocket module

## Cases bắt buộc

1. OTA trả đúng `websocket.url`.
2. Upgrade nhận `Device-Id`, `Client-Id`, `Protocol-Version`.
3. Client hello được deserialize khi có field mở rộng.
4. Server hello chứa `type=hello`, `transport=websocket`, `session_id`.
5. Binary v1 được forward nguyên payload vào event trước decode layer.
6. Unknown text message không panic.
7. Malformed JSON không đóng process.
8. Disconnect phát `SessionEvent::Disconnected`.
9. Single writer ưu tiên control hợp lệ hơn audio; `tts:start(gen N)` đến trước Opus đầu tiên và không Opus generation N nào tới WebSocket sau `tts:stop(gen N)`.
10. AwaitHello nhận binary, malformed/non-hello JSON hoặc hello mismatch -> close 1002, không tạo VoiceSession.
11. Sau handshake, một malformed/unknown/invalid/wrong-state application message -> metric + ignore, VoiceSession vẫn khỏe.
12. Text hoặc binary frame vượt `websocket.max_frame_bytes` -> close 1009 trước parse/decode.

## Example command

```bash
./scripts/test-module.sh ws
```

Reference Client có thể xác nhận binary downlink từ một conformance peer độc lập:

```bash
cargo run -p voice-reference-client -- --ota http://peer/voice/ota/ \
  receive-binary --expected-hex 00ff10
```

Lệnh hoàn tất OTA và `ClientHello`, rồi chỉ pass khi packet binary kế tiếp khớp chính xác fixture hex. Đây là seam conformance; nó không thêm message test-only vào wire protocol server.
